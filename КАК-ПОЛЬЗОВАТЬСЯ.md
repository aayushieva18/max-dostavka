# Как пользоваться — помощник по сборке MAX mini app «Доставка»

## Что это

Помощник, который вместе с тобой, шаг за шагом, собирает твоё мини-приложение
для мессенджера MAX: покупатели оформляют заказ на доставку, ты видишь заказы
на карте Яндекс, отмечаешь остатки товара и развозишь заказы.

**Важно:** проект был для VK, потом ты решила перейти только на MAX — весь код
переписан заново под MAX 2026-09-15. Папка проекта тоже переименована (была
`vk-доставка`, стала `max-доставка`). Твои реальные товары и заказы никуда
не делись, они на месте.

Готова и проверена версия: форма заказа у покупателя (с запоминанием
имени/адреса/телефона, адрес сам находится на карте), список товаров с +/- и
учётом остатков, у тебя — карта заказов, маршрут со временем прибытия к
каждой точке, возможность заводить и переименовывать товары, кнопка «заказ
выдал»; у покупателя — своё время прибытия и кнопка «заказ забрал». Работает
пока только на этом компьютере, не в настоящем MAX.

## Важно: нужно вписать твой id в MAX

Раньше в коде был твой VK id — теперь нужен твой id в MAX (это другое число).
Как узнать: открой приложение (см. ниже), нажми F12 (откроется панель
разработчика), вкладка Console — там будет строка «Твой id в MAX для этого
запуска: …». Пришли это число помощнику, он впишет его в код — тогда именно
тебе будет открываться экран хозяйки, а не экран покупателя.

## Как посмотреть, что получилось, прямо сейчас

Приложение состоит из двух частей, обе должны быть запущены одновременно:

1. Сервер — команда `npm run dev` в папке `server`.
2. Витрина — команда `npm run dev` в папке `client`.
3. Открой в браузере адрес, который покажет вторая команда (обычно
   `http://localhost:5173`).

Попроси помощника запустить оба, если не хочешь делать это сама — он умеет.

## Чего пока не хватает

- Твой настоящий id в MAX ещё не вписан (см. выше).
- Мини-приложение MAX обязательно нужно привязать к боту в MAX — это отдельный
  шаг регистрации перед публикацией, сделаем вместе, когда дойдём до него.
- Приложение работает только на этом компьютере — перед публикацией сервер
  нужно будет куда-то выложить, чтобы он был доступен всегда (это может быть
  платно — обсудим отдельно).
- Показ маршрута и товаров покупателю уже не через VK — не проходила полная
  проверка всего сценария заново на новом интерфейсе, стоит сделать вместе.

## Как позвать помощника дальше

Просто напиши что-то вроде:
- «продолжи собирать мой mini app»
- «вот мой id в MAX»
- «запусти приложение, хочу посмотреть»
- «давай регистрировать бота в MAX»

Помощник сам откроет свою память (`задача.md` и `сборка.md`) и продолжит с
того места, где остановились.

## Чего помощник никогда не сделает сам

- Не опубликует приложение и не зарегистрирует бота в MAX без тебя.
- Не тронет твой аккаунт в MAX.
- Не отправит код или данные проекта куда-либо наружу.
- Не установит ничего на компьютер без твоего явного «да» (первое «да» уже
  получено на пакеты для разработки этого проекта).

## Если что-то пошло не так

Просто опиши словами, что не так или что хочется поменять — помощник
подстроится и переделает. Файлы `задача.md` (что должно получиться) и
`сборка.md` (что уже сделано и что осталось) — это его память; заглядывать
туда самой не обязательно, но можно, если интересно посмотреть на прогресс.
